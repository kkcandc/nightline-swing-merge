# NIGHTLINE

A courier’s route through **Vesper Reach**, an original gothic night city. Throw luminous filament lines, keep the momentum when you release, and open a short cape to glide or dive-bomb between the towers.

No accounts. No keys. The whole run lives in the browser.

## Play

Live city: https://nightline.vercel.app

Or locally:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

Click **Enter the city** and allow the mouse to lock. Press Esc to pause.

## Controls

| Action | Binding |
| --- | --- |
| Look | Mouse |
| Run | W A S D |
| Sprint | Shift |
| Jump | Space |
| Cape-glide | Hold Space in the air (short stamina, refills on the ground or while swinging) |
| Throw a nightline | Hold left mouse or F on a tower |
| Let go, keep speed | Release the mouse or F |
| Reel in | Q, right mouse, or scroll up |
| Pay out line | E or scroll down |
| Dive-bomb | Hold Ctrl or C, release to pull out into a fast glide |
| Wall-run | Brush a wall in the air, Space to kick off |
| Return to safe footing | R |
| Restart the Night Circuit | T |
| Mute | M |
| Rain | G |
| Pause | Esc |

## What to do

- Thread the glowing gates from **Mourning Gate** to the crown of **Vesper Spire**. The timer starts when you pass the first gate. Your best time stays on this machine.
- Pick up signal orbs. They are saved in the browser. A fast chain of them shows on the HUD.
- The thin lit towers are the best anchors. Look where you want the arc to go; holding W pumps it.

Landmarks you can read in the skyline: Bellforge, Hollow Nave, Vesper Spire, Mourning Gate, Ashbridge, Cinder Row, Ironwharf.
